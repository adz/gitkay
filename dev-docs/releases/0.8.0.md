# GitKay 0.8.0

## Uncommitted changes from the history window

- **Stage, unstage and discard** straight from the "Uncommitted changes" rows: `s`, `u` and `Delete`, or right-click.
  Selected lines, a hunk or a whole file, exactly as the commit window does it.
- **Amend the newest commit** from its right-click menu, which opens the commit window with the commit's files in it.

## Discards you can take back

- Before anything is thrown away the files are copied inside the git directory, so a discard can be undone with
  `Ctrl+Z` or Undo in the commit window — the one thing git itself can't recover.
- An undo refuses to overwrite edits made since the discard, and points at the backup instead.

## Fixes

- **Markdown and plain text read as prose**, not code: headings, list markers, code spans and link targets get the
  colour, instead of English words being highlighted as keywords.
- **Branch and tag badges keep their room**: the commit column borrows width from the author column when a row's refs
  need it, like gitk, and gives it back.
- **No flashing around panes**: hovering follows the pointer across the whole pane, so crossing the strip between a
  pane's header and its content no longer blinks the effect off and on.
- **Collapsing a pinned file header no longer flashes**, and collapse and expand remember where you were reading.
- Amending shows the commit's files; `F5` rereads refs; the settings inputs line up.

## Configuration

- Settings and UI state live in `~/.config/gitkay` (lowercase) as just `settings.json` and `ui-state.json`: the recent
  searches and view preferences files are gone, folded into the UI state. Earlier settings are not carried over.
