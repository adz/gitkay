# GitKay 0.17.1

Fixes the file list and the diff naming different files when the file list is in tree mode.

## Fixed

- Opening a commit, or stepping through commits with the arrow keys, selected the first file of Git's patch order
  while the diff is ordered by the file tree (or the reverse in patch mode). The selection and the diff now come from
  the same order: the first file the file list displays. The selection is still reported back, so the highlighted file
  is always the file at the top of the diff.
