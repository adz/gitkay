# GitKay 0.2.1

## Fixes

- **The diagnostics window no longer crashes the app.** Opening it called `ToString()` on an F# union, which needs
  reflection that the NativeAOT build removes. Command failure logging had the same problem. GitKay now uses
  Axial 0.9.3, whose types render without reflection, and its build rejects reflection-based formatting (AXG006).
- `gitkay --self-test` runs the paths that only fail in the shipped binary. Every release runs it on Windows and
  Linux before publishing.
- The files splitter can no longer push the file list past the window edge.
- Advanced search fields no longer clip their placeholder text.

## New

- **Delete branch** from the commit context menu. A confirmation shows the branch tip and whether it is merged into
  HEAD, then deletion runs with live output.
- **Copy branch, remote branch or tag name** from the commit context menu.
- The **file filter** shows as a chip beside the search box, with a button to clear it.
- **Diff and files headers** align over their own columns. Find and the view modes end at the diff's edge.
- **Change totals** (`+added −removed`) on folder rows and in the files header; the list-mode toggle has a border.
- The author column shows the **email**, like gitk.
- **Error statuses** turn the footer red and pulse it.
