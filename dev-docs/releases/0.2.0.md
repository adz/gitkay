# GitKay 0.2.0

## Fixes

- **Commit search no longer crashes on large histories.** Typing a common term (for example `oc`) overflowed the
  stack in the search loop and terminated GitKay, immediately on Windows. Fixed in Axial 0.9.2, which GitKay now uses.
- **`gitkay <file>` works like `gitk <file>`.** A file or folder argument filters history to it, resolved relative to
  where you launched (Windows `\` separators work). Previously it was treated as an unknown revision and the window
  could sit on the loading screen.
- **History follows HEAD by default**, like gitk and `git log`. It previously loaded every ref, as if `--all` were
  given. `--all` and the new **All branches** toggle load everything.
- **The window no longer freezes while history loads.** Git work started on the UI thread; walking a large or
  path-filtered history blocked the window for seconds. Loading a large history also rebuilt the commit list once
  per commit (quadratic); it now rebuilds once.
- A startup failure now shows its error dialog instead of leaving no window.
- The status bar says what history is limited to (revisions and paths).

## New

- **Diagnostics window** (Ctrl+Shift+D): live Axial fibers, settled flows with timings, per-flow totals, failures with
  their causes, Elmish messages and update times, UI-thread lag, and the log. Copy a snapshot or write a report.
- **Logs and crash reports** always on: `%LOCALAPPDATA%\GitKay\logs` (Windows), `~/Library/Logs/GitKay` (macOS),
  `~/.local/state/gitkay/logs` (Linux). Crash and hang reports include recent messages and running flows.
- **Diff zoom** for diff text only: Ctrl+= / Ctrl+- / Ctrl+0 or Ctrl+wheel; remembered between sessions.
- **All files** list mode: every file in the commit as a tree, unchanged files included.
- **File context menu** (file list, file headers, code lines): select, copy full or relative path, show whole file,
  filter history to this file, open in VS Code (rooted at the repository, reusing an open window).
- **Whole-file popup** with all four diff modes.
- **Vim visual selection** in diffs: `v`/`V`, extend with `j`/`k`, yank with `y`.
- **Push and pull** a branch from the commit context menu, and **Fetch all remotes**, with live progress.
- **Open repository…** opens another repository in a new window.
- New application icon.
