# GitKay 0.10.0

## Highlights

- Diff scrolling is substantially smoother, including slow touchpad gestures.
- Diff code is shaped only for visible lines without delayed recolouring or layout-cache cliffs.
- Patch and tree file views now use the same file order as the displayed diff.
- The commit window shares diff settings and file-list modes with the history window.
- Added an ignore-whitespace diff option and improved diff navigation and resizing.
- Refreshed the README screenshots.

## Platforms

- Added native macOS builds for Intel (`osx-x64`) and Apple silicon (`osx-arm64`).
- Windows x64 and Linux x64 builds remain available.
