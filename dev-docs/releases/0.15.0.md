# GitKay 0.15.0

## Highlights

- The uncommitted-changes diff now expands context the same way a commit diff does. Each hidden run gets its arrows,
  the usual navigation and `H`/`M`/`L` work inside it, and an expansion is dropped when the file it belongs to
  changes under it.
- Rendered diffs — Markdown, and JSON and XML reformatted for reading — collapse unchanged runs into the same gap
  rows the source diff uses, with per-gap arrows. The file header still flips one file between the whole document
  and only what changed; the global **Collapse long unchanged runs** setting is gone, since each file now says so
  for itself.
- A `settings.json` or `ui-state.json` that cannot be read is reported in a dialog that names the file and the
  reason and offers to open it, or show it in its folder. GitKay carries on with the defaults and leaves the file
  as it is, instead of loading defaults quietly.

## Fixes

- The commit window's scroll viewer now notices rows that appear after the first layout, so the mouse wheel works
  without a click first.
- A re-rendered file releases the images of its previous render, so a stale picture cannot sit under a new one.
- The history, commit, folder and whole-file surfaces share one image state, removing the separate old/new image
  properties that could drift apart.

## Under the hood

- Application decisions move out of the C# UI and into `GitKay.Core` and `GitKay.Serialization`: the settings and
  UI-state stores, git inspection, diff expansion, and the view-model projections. C# keeps Avalonia drawing,
  input and binding. `dev-docs/csharp-fsharp-migration.md` records what has moved and the order for the rest.
- Commands run as named fibers on one shared `AxialElmishRuntime` instead of per-command latest-job slots. They
  start on the thread pool, so a slow command no longer delays the UI thread while it begins, and closing a window
  cancels everything that window started. The diagnostics registry is Axial's `FiberRegistry` rather than a
  hand-rolled one.
- One `Timing` module over Axial's injectable clock is the only source of the durations the UI reports, replacing
  `Stopwatch` throughout; the self-test runs against a manual clock.
- The working-tree watcher and the search box share one Axial stream debounce, and the diff cache is one Axial
  `Cache` per repository instead of a dictionary of fibers behind a manual claim/release gate.
- Axial moves to 0.10.

## Development

- The README now describes what GitKay does and how to build it from source.
