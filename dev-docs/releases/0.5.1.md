# GitKay 0.5.1

## Fixes

- **"Only commits on <branch>" shows the branch's history.** It used to add a search for the branch name, which only
  matched the commit carrying the label. It now limits history to what the branch reaches, from its head back (like
  `gitk <branch>`), keeping any file filter. A chip names the branch; ✕ returns to the full history, and choosing all
  branches replaces it.
- **Collapsing a file whose header is stuck to the top keeps it there.** When scrolled into a long file, collapsing
  it from the sticky header jumped the view past the file.
- Removed "Select" from the file context menus: it selected the row you had already right-clicked.
