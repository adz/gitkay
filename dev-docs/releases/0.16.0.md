# GitKay 0.16.0

## Highlights

- Remote images in Markdown previews now have a size limit and timeout, so a slow or oversized image cannot hold up the preview indefinitely.
- Switching repositories and closing GitKay now stop work associated with the previous repository, including cached diff work.

## Under the hood

- GitKay moves to the released Axial 0.11.0, Reified 0.11.0 and Elmish Glue 0.2.0 packages. Commands and repository caches now use the packaged flow runtime and scoped resources.
