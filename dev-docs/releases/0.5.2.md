# GitKay 0.5.2

## Fixes

- **Collapsing a file from its sticky header keeps the header exactly in place.** 0.5.1 still moved it down by a
  small margin.
- **The branch and file filter chips show their ✕.** The close buttons were there but drew nothing; clicking ✕ clears
  that filter.
- **The branch chip has a menu** on click or right-click, like the file chip: show the full history, show all
  branches, or copy the name.
