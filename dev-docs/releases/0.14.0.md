# GitKay 0.14.0

## Highlights

- URLs in git operation output are now clickable, including the "View pull request" link a push prints. Push, pull, fetch and delete-branch output, and a failed commit's output, open the link in your default browser; dragging still selects text.
- The window title shows the repository's path (with `~` for your home folder) instead of always saying "GitKay".

## Fixes

- Scrolling a row into view in the diff (`j`/`k`, `]c`/`[c`, go to line, search hits, `H`/`M`/`L`, `zt`/`zz`) no longer leaves it under the pinned file header.
- Collapsing a file in the diff no longer jumps the view to the top when little content remains below it; the collapsed header stays where it was.
- The UI no longer saves its state to disk on the UI thread each time you select a commit, and comparing revisions lists branches off the UI thread. Rendered Markdown remembers row heights instead of re-measuring every word on each layout.
- Hang reports now say which part of the UI the thread was inside, and slow UI work over 250 ms is logged as `[slow]`. On Windows a hang also writes a `.dmp` file beside the report with every thread's stack.

## Development

- macOS builds now run only in the release workflow, not on every pull request.
