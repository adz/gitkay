# GitKay 0.3.0

## Search

- **Much faster Path and Diff searches.** Commit metadata filters first; only the remaining commits have their contents
  read, by parallel workers with their own repository handles. Path search compares trees without reading patches or
  detecting renames: a path search over a 10,000-commit repository went from about 2.5 minutes to under 9 seconds.
  Diff search skips binary files and files over 2 MB, and libgit2's blob cache is enabled, roughly halving how much
  it re-reads between neighbouring commits.
- **Results stream in** while the search runs, in history order, with progress ("4,200 of 10,579 commits, 231
  matches so far").
- **Cancel** a running search with Esc (the query stays), or cancel any running operation from the diagnostics window.
- **Dates that don't parse** in `after:`/`before:` are reported instead of silently ignored, and the advanced date
  fields turn red.

## History

- **File-limited history is near-instant.** `gitkay <file>` and "Filter history to this file" ask `git log`, which uses
  commit-graph changed-path Bloom filters: a file's history in a 10,000-commit repository loads in under half a second.
  GitKay falls back to reading history itself when `git` isn't available.
- The file filter shows as a compact **FILE FILTERED** chip; hover shows the path and right-click or click offers
  actions.

## Memory

- On Linux, native memory that libgit2 has freed is returned to the OS after heavy work. A full-history search used to
  leave about 1 GB resident; it now returns to about 110 MB. The diagnostics window shows native memory and how much
  was returned.

## Also

- **The commit context menu opens for the commit you right-click.** It was showing the previous selection's menu,
  which hid branch actions such as delete, push and pull.
- **About GitKay** shows the release version, the commit it was built from, runtime and platform.
- **Diagnostics:** flow details (info button or double-click) with timings, parent fiber, annotations, failure cause
  and defect; cancel from the Running tab.
- Home and End jump to the first and last row.
- Zoom commands are no longer in the menu (Ctrl+=, Ctrl+-, Ctrl+0 and Ctrl+wheel still work).
