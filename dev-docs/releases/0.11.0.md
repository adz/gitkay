# GitKay 0.11.0

## Highlights

- Render Markdown files directly in the diff pane and whole-file window, with rich prose, tables, lists, code blocks, links and revision-correct images.
- Rendered Markdown diffs align document blocks, highlight changed words and code lines, detect moved blocks, and support unified, old, new and side-by-side layouts.
- Added exact text selection across wrapped rendered prose, stable viewport anchoring, changes-only mode, Markdown search/navigation, and persisted per-file preview preferences.
- Added three-dot comparisons between arbitrary branches, tags and commits.
- Added safe, explicit loading for remote Markdown images; repository images are loaded from the correct old and new revisions.

## Fixes and packaging

- Added and untracked Markdown files now offer both diff and whole-file previews.
- Inline code aligns correctly with surrounding prose.
- Linux NativeAOT release binaries no longer embed native debug symbols, substantially reducing download size.
- NativeAOT publishing and self-tests cover Linux, Windows, Intel macOS and Apple silicon macOS.
