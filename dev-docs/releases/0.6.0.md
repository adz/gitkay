# GitKay 0.6.0

## Uncommitted changes

- **An "Uncommitted changes" row sits above the newest commit** when the working tree or index differs from HEAD: a
  dashed node joined to HEAD, with counts ("1 staged · 2 unstaged · 1 untracked") where a commit shows its subject.
- **Selecting it shows the changes in Staged, Unstaged and Untracked sections**, in the files list (flat and tree) and
  in the diff pane, where clicking a section header collapses it. A file changed in both the index and the working
  tree appears in both. The all-files tree marks files ● staged, ○ unstaged, ◐ both, + untracked.
- **It stays current:** a file watcher refreshes it shortly after files change, and so does returning to the window.
  If everything is committed while it's selected, the newest commit is selected instead.
- Context expansion, "Show whole file", VS Code and the file menus work on uncommitted files. Commit actions (tags,
  branches, reset, copy hash) aren't offered on the row.

## Graph and refs

- **The commit graph is continuous:** lines no longer break at each commit, lane changes are smooth curves, each
  branch line keeps its colour, and merge commits are rings. Dark mode uses a softer lane palette.
- **Lines run from a commit out to its branches and tags**, like gitk. Tags are drawn as tags; branches as boxes.
- **Darker text in light mode.**
