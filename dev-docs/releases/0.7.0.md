# GitKay 0.7.0

## The commit window

A separate window for staging and committing, like git gui beside gitk. The history window stays read-only.

- **Open it** with `gitkay gui` (or the `gitkay-gui` command installed beside `gitkay`), which opens only the commit
  window and exits when you close it. From the history: `Ctrl+Shift+C`, the menu, or Enter or a double-click on the
  "Uncommitted changes" row.
- **Unstaged Changes** and **Staged Changes (Will Commit)** run down the left, coloured as in git gui, with the current
  branch across the top and the message box beside the diff.
- **Stage and unstage** whole files (Enter, double-click, `s` / `u`, `Ctrl+S` / `Ctrl+U`, or Stage all), a hunk, or just
  the lines you select. **Discard** (Delete) throws away selected lines or a file's changes after asking.
- **Commit** with `Ctrl+Enter`, **amend**, **sign off** (`Ctrl+S` in the message), or **Commit and push**. Hooks run, and
  their output is shown if a commit fails, with your message kept.
- **Searching and moving** work as in the main window: `/` and `?` with `n` / `N` and `*` / `#`, `Ctrl+P` to jump to any
  changed file in either list, `Ctrl+1`–`4` and `Ctrl+W` for panes, and the vim movement keys. **F1** lists them all.
- Line staging builds a patch of just the chosen lines from a fresh diff, and checks the lines still match before
  applying, so a file that changed underneath says "rescan" instead of staging the wrong thing.

## Panes and contrast

- **Space around panes**, 0–8 pixels, and a **hover effect** in that space — glow, shadow or highlight — with a
  **colour** and an **intensity** (full, half, quarter, eighth). All in Settings, for both windows.
- **More contrast between the chrome and the content:** bars, headers and panels step away from the diff background in
  both themes, and buttons now have a fill and edge that stand apart from labels. Commit is a filled accent button.
- Hovering a text box or combo box picks up a quiet accent edge instead of a bright fill.

## Fixes

- Opening `/` in the commit window no longer shifts the diff: transient prompts overlay content rather than resizing it.
- The commit window takes keyboard focus when opened from the history, so keys don't go to the window behind.
