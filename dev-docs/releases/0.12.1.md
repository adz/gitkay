# GitKay 0.12.1

Fixes for 0.12.0.

- A reformatted JSON or XML preview is no longer replaced by the file's source a moment after it opens, which is why "preview by default" appeared to do nothing for those formats. Every model update re-syncs the selected files; the preview is now kept and the source held aside as the restore point. Rendered Markdown was unaffected because it keeps its own rows.
- The preview control in a file header is now a labelled pill reading **Preview** or **Source**, filled while previewing. A rendered Markdown file is obviously rendered, but reformatted JSON and XML are still text, so a tinted icon said nothing about which one was showing.
- In the commit window, a file staged line by line appears in both lists; selecting one side left the other side's row still selected, so clicking it raised nothing and the file could not be reached until something else was selected first.
- The commit window no longer loses focus to the history window behind it: hover-to-focus fired even when the history window was inactive, and focusing a control there activated it.
- Staged files can now be discarded from their context menu, unstaging and discarding in one step. Discard was previously offered only on the unstaged side of the same file.
- "Open in VS Code" uses a clearer glyph; VS Code's own crossed ribbon reads as a pair of scissors at 16 pixels.
